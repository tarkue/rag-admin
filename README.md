# Moodle Knowledge — админка

Next.js App Router, React, TypeScript, Tailwind CSS 4 и shadcn/ui. Отдельный frontend для `../rag-service`.

## Запуск

```bash
npm install
cp .env.example .env.local
# Заполнить серверные переменные в .env.local
npm run dev
```

Открыть http://localhost:3000. Задайте логин и пароль через `ADMIN_LOGIN` и `ADMIN_PASSWORD` в `.env.local`. Пароль в публичном шаблоне намеренно пустой; при пустом пароле вход закрыт. После изменения переменных перезапустить Next.js.

`RAG_ADMIN_TOKEN` должен совпадать с `ADMIN_SERVICE_TOKEN` FastAPI, а `RAG_SERVICE_TOKEN` — с `SERVICE_TOKEN`. Запустить FastAPI и Chroma в `../rag-service`. Ключ и модель OpenRouter можно сохранить прямо на странице настроек; перезапуск FastAPI не нужен.

`SESSION_SECRET` — случайная строка не короче 32 символов. Сгенерировать: `openssl rand -hex 32`. В `.env.example` секрет сессии пустой; вход без него закрыт. Для HTTPS установить `COOKIE_SECURE=true`; локально через HTTP оставить `false`.

## Возможности

- Обзор: реальные документы, фрагменты, курсы, состояние API и Chroma.
- Документы: поиск, фильтр по курсу, пагинация, загрузка PDF/DOCX/PPTX до 30 МБ, удаление с подтверждением, переиндексация Moodle-документов.
- Настройки: OpenRouter или Ollama, API-ключ, поиск, переранжирование, обработка документов, системный промпт.
- Файлы ручной загрузки обновляются повторной загрузкой с тем же ID документа. Исходные файлы FastAPI не сохраняет.

## Авторизация

Одна учётная запись из окружения. Подписанная сервером сессия в HttpOnly-cookie действует 8 часов. Изменение логина или пароля инвалидирует прежние сессии. Серверные функции повторно проверяют сессию перед каждым обращением к FastAPI. Логин ограничен 8 неудачными попытками в минуту на экземпляр приложения. Это локальная однопользовательская панель; при нескольких экземплярах нужен общий лимитер.

Ни один секрет не использует префикс `NEXT_PUBLIC_`. Сервисные токены хранятся только на сервере Next.js. API-ключ OpenRouter отправляется авторизованной серверной функцией и не возвращается в ответе. Runtime-настройки FastAPI сохраняет в собственный `data/runtime_config.json`.

## Сборка

```bash
npm run build
npm start
```

Проверка TypeScript: `npm run typecheck`. Компоненты shadcn лежат в `components/ui` и могут обновляться обычным CLI shadcn.

## Проверки и локальная QA-копия

`npm test` запускает регрессионные проверки найденных при review ошибок. Нужен Node.js 22.13+.

Для проверки интерфейса без изменения рабочей базы (Postman CLI 1.75+):

```bash
# Терминал 1
npm run qa:api
# Терминал 2
npm run dev:qa
```

Откройте http://127.0.0.1:3002. Используются синтетические документы и настройки; генерация ответов и индексатор не запускаются. Обычный `npm run dev` использует рабочий API из `.env.local`.
