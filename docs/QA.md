# Проверка перед первой публикацией

Дата: 29 октября 2026.

Проведены независимые review авторизации/безопасности, функциональности и UI/UX. После исправлений выполнено повторное review.

## Ручной прогон в Google Chrome

Обычный desktop viewport, мобильные размеры **375×667** и **390×844**. Действия выполнялись через реальный интерфейс Next.js и его Server Actions. Мутации выполнялись против локальной Postman simulation с синтетическими данными; рабочая база документов не менялась.

| Область | Проверено |
| --- | --- |
| Авторизация | Неверный пароль, успешный вход, показ/скрытие пароля, выход, перенаправление неавторизованного пользователя с `/documents` на `/login` |
| Обзор | Реальные ответы симуляции, число документов/фрагментов/курсов, переходы в разделы |
| Документы | Обе страницы пагинации, поиск, пустой результат, сброс фильтров, отдельная фильтрация курса с ID `all` |
| Действия с документами | Переиндексация Moodle-документа, запрет переиндексации ручной загрузки, отмена удаления, подтверждение удаления и обновление списка |
| Загрузка | Выбор синтетического PDF через системное окно macOS, все поля метаданных, отклонение ID со слэшем, успешная multipart-загрузка и появление записи |
| Модель | OpenRouter, синтетический ключ, его показ/скрытие и маскирование после сохранения, переключение на Ollama и обратно, изменение времени ожидания |
| Поиск | Число фрагментов, объём контекста, режим поиска, включение переранжирования и проверка ответа, число кандидатов |
| Обработка | Размер и перекрытие фрагментов, смена PDF-парсера и стратегии, уведомление о необходимости переиндексации |
| Промпт | Отклонение неизвестной переменной, сохранение допустимого промпта с экранированными скобками, отмена изменений |
| Ошибки | API 422 при сохранении: сообщение и сохранность введённых значений; API 502: понятный экран; восстановление после возврата API |
| Навигация | Все страницы панели, 404 и возврат из неё |
| Мобильный интерфейс | Обзор, документы, настройки, горизонтальная прокрутка вкладок, меню и Escape, все поля и нижние кнопки прокручиваемой формы загрузки |

На проверенных мобильных страницах `document.documentElement.scrollWidth` равен ширине viewport; широкая таблица прокручивается внутри контейнера. Консоль Chrome на финальном прогоне — без ошибок и предупреждений.

## Автоматические проверки

`npm test`: 6 регрессионных проверок парсера промпта, ID документа, совместимости старых ID при удалении, фильтра курса `all` и календарной даты в отрицательном часовом поясе.

`npm run typecheck` и `npm run build`: проверка TypeScript и production-сборка.

## Границы проверки

Postman fixture повторяет используемые формы запросов из `rag-service/schemas/admin.py` и `routers/ingest.py`. Логи simulation подтвердили вызовы документов, загрузки, удаления, переиндексации и PATCH настроек. Она не выполняет парсинг/эмбеддинги, не запускает LLM и не проверяет качество RAG-ответов. Реальные ключи OpenRouter при проверке форм не использовались. Доступность рабочего FastAPI и Chroma проверена отдельно чтением health endpoint.

Ограничение расширения Chrome для `filechooser.setFiles` обошли поддерживаемым системным выбором файла; дополнительные разрешения браузеру не выдавались. Повторный выбор того же файла исправлен очисткой input до обработки File и проверен при review исходников; отдельный повторный прогон этого edge case через расширение не завершён. Проверки размера/расширения файлов присутствуют на клиенте и сервере, но не заявлены здесь как отдельные пройденные браузерные сценарии.
